Проект: интерактивная кластеризация dbscan
Описание:
Проект реализован без использования готовых ML-библиотек.
Алгоритм DBSCAN написан с нуля на Python, для визуализации используется Pygame. 

В задачи входило:
  -Реализация алгоритма DBSCAN (поиск соседей, определение ядровых точек, построение кластеров через компоненты связности графа)
  -Интерактивное добавление точек левой кнопкой мыши с мгновенным пересчётом кластеров
  -Каждый кластер получает уникальный стабильный цвет, шумовые точки — красный

Запуск: python main.py
